How It Works — Three Pipelines

Old vs New — What Changed?

Aspect ArcGIS (Before) Cloud-Native (After)
Architecture Monolithic server Microservices (6 containers)
Compute Always-on VMs Serverless (ECS Fargate + Lambda)
Database ArcSDE + SQLServer PostGIS (open-source)
Map Rendering ArcGIS JS API (proprietary) MapLibre GL JS (open-source)
Tile Format Raster tiles (PNG/JPEG) OGC Vector Tiles (.pbf)
Data Update Manual publish/overwrite S3 upload → auto pipeline (6 hrs)
Authentication ArcGIS Portal logins AWS Cognito (OAuth 2.0 / OIDC)
Deployment Manual install + config Terraform IaC + CI/CD (14 pipelines)
Vendor Lock-in Esri ecosystem 100% open-source stack
Monthly Cost $$$$ (licensing + infra) ~$50/month (AWS only)

  • Security scanning (Checkov) on every change
  • OIDC auth — no stored secrets in CI/CD
